Notebook 00 · Javi

Fotometría barata, espectroscopía cara

Un survey como el SDSS fotografía el cielo y mide, para cada objeto, cinco magnitudes de brillo (u, g, r, i, z) — esto es barato y se hace automáticamente para millones de objetos.

Pero confirmar si un objeto es estrella, galaxia o cuásar requiere espectroscopía: apuntar el telescopio a ese objeto específico. Recurso caro y escaso, muy disputado entre equipos de investigación.

  • La pregunta de negocio: ¿podemos agrupar objetos usando solo el dato barato, para priorizar dónde gastar el recurso caro?
  • Un objeto recién fotografiado no tiene todavía clase real — el pipeline debe actuar como si esa etiqueta no existiera.
  • class se retira del modelado y se reserva únicamente para validar el resultado al final.

Nota: a diferencia de otros pipelines de este tipo, aquí redshift se conserva como feature — también requiere espectroscopía, pero el equipo decidió incluirlo como señal de entrada válida en lugar de reservarlo solo para validación.

Ingeniería de variables: índices de color

Las diferencias entre bandas son más informativas que las magnitudes absolutas:

color_ug = u − g
color_gr = g − r
color_ri = r − i
color_iz = i − z

Escalado final con RobustScaler (mediana y rango intercuartílico) — más resistente a outliers que un escalado estándar.

Cuatro algoritmos comparados, un ganador

Objetos proyectados en PCA (coloreados por cluster de K-Means)

Tamaño de cada cluster (K-Means, ganador)

Comparación contra la clase real (nunca usada al entrenar)

DBSCAN colapsó casi todo en una sola megaclase (ARI≈0.006). K-Means ofrece el mejor equilibrio entre las 3 clases y el mejor desempeño en QSO (F1=0.81).

K-Means (K=3) se lleva a producción por su balance entre clases; GMM tiene mejor NMI y precisión en galaxias, Jerárquico el ARI más alto pero falla en estrellas, DBSCAN no encontró estructura real con estos hiperparámetros.

Composición real de cada cluster

Validación honesta contra la clase real — Índice de Rand Ajustado = : concordancia real pero moderada, no un clasificador perfecto.

¿Por qué esto es un resultado útil?

Un ARI moderado es exactamente lo esperable si la fotometría es parcialmente informativa pero no reemplaza la espectroscopía. El producto correcto no es un "clasificador automático" — es una herramienta de triage que prioriza qué observar primero.

Notebook 05 · Yohanna

Análisis ético

Automatizar qué se observa no es neutral — moldea qué descubre la ciencia y qué queda sin observar.

Sesgo de descubrimientoUn triage mal calibrado puede filtrar hacia abajo exactamente los objetos más atípicos — el hallazgo más valioso en astronomía.
Sesgo instrumentalSe descartaron deliberadamente las columnas de instrumento para no aprender patrones del telescopio en vez del objeto.
Desempeño desigual entre clasesSTAR es sistemáticamente la clase peor identificada en los 4 modelos (F1 entre 0.31 y 0.50) — sus recomendaciones merecen menos confianza.
Sin verdad de referencia futuraEl ARI se validó contra el archivo histórico; para objetos nuevos, la calidad solo se confirma con futuras confirmaciones.

Salvaguardas: usar el triage solo para ordenar una cola, nunca para descartar sin revisión humana; comunicar la menor confiabilidad en candidatos a estrella; re-validar con cada nuevo lote de confirmaciones; publicar el perfil de cada cluster para auditoría del comité científico.

Más allá del cielo

  • Manufactura: priorizar qué lotes necesitan inspección de calidad costosa.
